我的 Mac 能用吗？Will it work on my Mac?+

Orbit 运行于 macOS 14 及更新版本。尚未公开发布，正式下载时会注明安装包支持的芯片架构。Orbit runs on macOS 14 and later. It has not been publicly released yet. Supported chip architectures will be listed with the download.

一定要用 ⌥Tab 吗？Do I have to use ⌥Tab?+

不用。在「设置 → 怎么打开」录入顺手的快捷键即可。也可以选鼠标中键或侧键；鼠标触发需要辅助功能权限。No. Choose a shortcut in Settings → Opening. You can also use a middle or side mouse button; mouse activation needs Accessibility permission.

没选好就松手，会误开吗？What if I release without choosing?+

指针还在中央死区时，松手直接收起，什么也不打开。想取消也可以按 Esc。「取消」实机演示展示的就是这个动作。If the pointer is in the central dead zone, releasing closes the wheel without opening anything. Esc cancels too. The Cancel recording shows this gesture.

会上传我的配置吗？Where does my setup live?+

轮盘配置保存在 Mac 本地，支持导入导出。基础启动功能不需要联网；授权激活与校验会联系授权服务。你打开的网页和自己设置的脚本可能访问网络。Your configuration is stored locally and supports import/export. Basic launching needs no connection. Activation and license checks contact a licensing service. Websites and your own scripts may access the network.

基础功能包括一个主轮盘、每盘 3–12 格、应用、文件、网页、系统操作、外观自定义和导入导出。子轮盘、多主轮盘、Shell 与 AppleScript 属于授权功能。永久激活 ¥9.9；验证邮箱后可免费试用 3 天全部功能，无自动扣款。当前尚未开售，正在准备正式发布。Core features include one main wheel with 3–12 slots, apps, files, websites, system actions, appearance settings, and import/export.
